# Course website sources and material

The readable course site uses source-backed Markdown in frontend/src/data/course-pages/ and frontend/src/data/milestones/. Home includes the original course overview, prerequisites, logistics, support format and project expectations in overview.md. Four public Markdown summaries in backend/knowledge/ (general.md, lectures.md, milestones.md, and project.md) supply the course chat; catalog.json describes their scope. Update the notes and course UI together when dates, policies, people, or requirements change.

The default frontend now runs without the backend. Chat code is retained and can be enabled with VITE_ENABLE_CHAT=true; the default output has no chat entry points or API requests. The original readings list is stored in readings.md and rendered at /readings.html. The five instruction sets also render as full static pages at /milestone1.html through /milestone5.html. These replace the remaining runtime links to the retired old course site. Ed, Canvas, the live schedule and external tutorials remain intentional resource links.

On 6 November 2026, three independent content reviews compared policies/FAQs, milestones and tutorials with the current original site. The live published schedule CSV was unchanged. The Tutorials source had changed and was refreshed; the missing syllabus text was restored on Home at the instructor's request. The Policy and FAQ wording and all five milestone instruction sets remain unchanged. pages-provenance.json records the current source SHAs, approved transformations, link checks and inherited source wording issues. Authenticated Ed, Canvas, Colab and Slides content was not inspected; no paid model calls or tutorial executions were used for this content review.

- [Ed Discussion](https://edstem.org/us/courses/97373/discussion) and [Ed Lectures](https://edstem.org/us/courses/97373/lessons): the course links supplied by the instructor. Their authenticated content was not downloaded or used as a knowledge source.
- [Harvard SEAS](https://seas.harvard.edu/): the official inline SVG logo, stored as frontend/public/brand/seas-logo.svg. Its shield geometry and colors are preserved. Dark mode reverses the wordmark ink; light mode preserves its original crimson and dark text.
- [SEAS logo guidance](https://seas.harvard.edu/office-communications/brand-style-guide/logos-templates): treat the logo as artwork; do not redraw the shield.
- [Harvard SEAS SEC tour](https://seas.harvard.edu/tour/allston/1/science-and-engineering-complex-sec) and [Behnisch SEC project](https://behnisch.com/work/projects/0274): building context and massing reference, alongside three photographs supplied by the instructor. No third-party building mesh is shipped.
- [Harvard SEAS classrooms](https://seas.harvard.edu/tour/allston/11/classrooms): Winokur Family Hall, SEC 1.321, has capacity for 300 and is accessed from the West Atrium. The instructor supplied photographs of the hall and atrium, marked the seating direction, and specified first-floor access, a position deeper inside the building, curved seating rows, and three rear entrances with white double doors and a vestibule. A further close-up shows the raised rear seating behind a cross-aisle. The original mesh represents 240 main seats in eight 30-seat rows and 60 rear seats in two 30-seat rows split into two raised banks. This row layout is an approximation, not a measured floor plan.
- [LangChain tools](https://docs.langchain.com/oss/python/langchain/tools) and [model tool loop](https://docs.langchain.com/oss/python/langchain/models#tool-execution-loop): the model chooses a filename, the server executes the read, and the result returns as a matching tool message. A local HTTP fixture verifies this protocol without a paid request.
- [FastAPI](https://fastapi.tiangolo.com/tutorial/body/): typed question validation and public API.
- [shadcn Base UI Dialog](https://ui.shadcn.com/docs/components/base/dialog), [Collapsible](https://ui.shadcn.com/docs/components/base/collapsible), [Field](https://ui.shadcn.com/docs/components/base/field), and [Button](https://ui.shadcn.com/docs/components/base/button): the floating chat and accessible controls. The CLI is not cached offline; official docs and installed Base UI source were inspected.
- [Geologica OFL](https://github.com/google/fonts/blob/main/ofl/geologica/OFL.txt): the self-hosted font's license is included in frontend/public/fonts/OFL.txt.

The SEC is an original solid architectural reconstruction based on the reference views, not a surveyed BIM or photogrammetry asset. It includes three stepped lower floors, planted roof terraces, glazed atria, unequal upper laboratory wings, folded screen modules and roof equipment. Materials retain silver, blue glass and green planting. Dark mode adds warm interior lights. The transparent ground and edge mask blend into the page. Day/night exterior and classroom PNG views are captured from the actual models for loading and mobile views.

The interior includes a broad atrium with yellow cafe chairs and round pendant lights, three rear vestibule entrances, curved tiered red/orange/gold seating, black acoustic walls, a folded pale ceiling and three projection screens. The middle projection screen is the largest, as requested by the instructor. A defocused transition allows the camera to pass through the continuous exterior wall. Two sequential white double-door sets open along the central vestibule route as the camera approaches. Pavlos Protopapas's current portrait is the PNG supplied by the instructor, stored as frontend/public/staff/pavlos-protopapas.png.

Downloads were stored and inspected on the designated test VPS under ~/internet-downloads/ac215-course-showcase/. Three.js archive integrity was checked against its registry SHA512. Dependencies were transferred for offline local builds; third-party package code was not run on the VPS. No cloud resources or paid model calls were used for this replacement.
